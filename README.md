En este repositorio se encuentran varios códigos de Python enfocados en econometría y estadística. 
Primero tenemos las agujas de Buffon: un clásico problema de probabilidad geométrica, de realización práctica para ir aproximando el valor del número π a partir de sucesivos intentos.
Luego tenemos una muestra del Teorema del Limite Central: Donde vemos que con muestras aleatorias suficientemente grandes, la distribución de la media muestral seguirá una distribución normal
Después hay un ejercicio de Regresión Lineal: Usada para modelar una variable dependiente sobre una o mas variables independientes
Finalmente cuento con unos ejercicios variados de estadística con varías pruebas, usados para ejercicios pero parten como base para casos futuros



Después de esto comparto mi información de mi proyecto final de econometría, regresión de variables múltiples para intentar determinar el INPC, esto junto con varías pruebas econométricas
